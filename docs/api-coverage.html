Reachable Surface Architecture

Every one of the 3014 reachable operations in the Autotask REST API is accessible through the MCP server:

  • Curated Tools: High-frequency workflows for tickets, ticket notes, ticket charges, companies, contacts, projects, tasks, time entries, contracts, contract services, services, and invoices.
  • Full Registry Escape Hatch: search_api(query, limit?) and call_api(tool_name, args) to search and invoke any operation in the registry.
  • Spec-Driven Generic Tools: query-entity, get-entity, create-entity, update-entity, delete-entity auto-resolve parent-child routes and foreign keys.

Security and Authorization Controls

  • Read-Only Mode: Mutating operations are never registered or callable when read-only mode is active.
  • Per-User Autotask Rights: Security level capabilities (read, create, update, delete) are checked per request.
  • Destructive Confirmation: Destructive operations require confirmation tokens and MCP elicitation.
  • Rate Limiting: Tenant-wide budget governor gates every call.
